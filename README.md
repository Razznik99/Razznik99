# 💫 About Me:

My experience spans full-stack web development, where I’ve designed and delivered responsive websites and landing pages for clients, as well as backend-driven applications using Java and Python.<br><br>I’ve worked on projects ranging from a Java-based School Management System built with solid OOP principles to freelance web solutions tailored to business needs.
